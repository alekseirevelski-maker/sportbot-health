# СИСТЕМА ЗДОРОВЬЯ СПОРТСМЕНОВ «ЧБК» — Telegram-бот

Это полный комплект исходников Telegram-бота для мониторинга здоровья баскетболистов (спортивная медицина). Бот собирает ежедневные опросы самочувствия, анкеты, считает Hooper-индекс, определяет фазы менструального цикла, строит Excel-отчёты для врача.

Файл подготовлен для просмотра/проверки другими нейросетями. Здесь весь код + описание + обезличенная схема БД.

---

## ⚠️ АНОНИМИЗАЦИЯ
- Токен бота НЕ включён (данные реального прод-бота).
- БД включена только как **схема + обезличенные примеры** (`DB_schema_обезличено.txt`) — телефоны/имена замаскированы, тексты жалоб заменены.
- Код полный, идентичен рабочему.

---

## КРАТКОЕ ОПИСАНИЕ
- **Язык:** Python 3.12, `python-telegram-bot >= 20` (класс `Application`, без ConversationHandler — состояния вручную в `user_states` dict), SQLite.
- **Назначение:** врач (админ) следит за ежедневным состоянием спортсменов через опросы (сон, стресс, утомление, боль, настроение, пульс, sRPE) и анкеты (медицинская справка).
- **Сервер:** Linux, systemd-служба `sport-health`.
- **Протоколы опроса:** Simple (U14-U16, 3 вопроса Hooper) и Full (U17+, 5 вопросов + пульс + sRPE).

## ФУНКЦИОНАЛ

### Регистрация
- Ввод «Имя и Фамилия», выбор возрастной группы (Simple/Full), выбор команды (из `TEAMS`).
- Пол (девушкам — вопросы цикла), у девушек — длина цикла (кнопки 21/24/28/30/35/**«Ввести число»** 21-35; «Не знаю»→28), сохраняется в `athletes.cycle_length_default`.

### Ежедневный опрос (Full)
Порядок: Сон→Стресс→Утомление→Боль→Настроение→ **Пульс** (ввод числа; подсказка «измеряй утром, как проснулся, лёжа в кровати, 15 сек×4») → sRPE (1-10) → (девушкам) **день цикла** (кнопки-диапазоны или **«Ввести число»** 1-длина цикла) → жалобы → финал.
- Hooper-индекс = Сон+Стресс+Утомл+Боль+Настроение (сумма /35). Интерпретация «уровень готовности»: ≥28 отлично, 20-27 средне, <20 низко.
- Шкала 1-7: **7=отлично**. Цвета: 6-7🟢 / 4-5🟡 / 1-3🔴.
- Фазы цикла: месячная 1-5, фолликулярная 6-13, овуляция 14-15, лютеиновая 16-28 + рекомендации.

### Меню спортсмена (минимально)
📝 Пройти опрос | 📊 Мои показатели | ⌚ Данные часов | 📋 Заполнить анкету | 📅 Запись к врачу | ❓ Помощь.
Админу дополнительно: 📋 Отчёт для врача | 📊 Экспорт в Excel | ⚙️ Управление.

### Анкета баскетболиста (одноразовая мед. справка, автосохранение + resume)
Блоки:
1. **Общие данные**: Возраст → **Телефон** (обязат.) → **Дата рождения** (ДД.ММ.ГГГГ) → Пол → Позиция → Уровень → Стаж → Рост/Вес.
2. **Травмы/здоровье**: Травмы 12 мес → зоны → боль сейчас → рецидивы → **Операции** (Да→«какие»→«дата/год») → Лекарства/БАДы → **Аллергии** (Да→«на что»).
3. **Тренировочный режим**: тренировок/нед (0-10) → длительность → сезон → форма (1-10) → сон (1-10) → разминка → восстановление.
4. **Питание**: вода → план питания → за сколько ест → **Спортпит** (мультивыбор ✅/⬜: Протеин/Креатин/Хондро/Изотоники/Кофеин/Ничего + «Другое» со свободным вводом).
5. **Психология**: мотивация (1-10) → внешний стресс → состояние перед матчем → страх травмы.
6. **Цели**: цель → пожелания.

Сохранение в таблицу `questionnaires`. Автосохранение после каждого шага (`state["q_data"]`), resume при продолжении.

### Врач / админ-панель
- 📋 **Отчёт для врача**: сводка по командам (АКS/участие/средние) + карточки.
- 📊 **Экспорт в Excel**:
  - *Отчёт по командам* (`generate_xlsx_report`): лист «Сводка» + по листу на команду — **матрица «ИГРОК-СТРОКА / ДЕНЬ-СТОЛБЕЦ / ПОДСТОЛБЦЫ=ПОКАЗАТЕЛИ»** (Сон,Стресс,Утомл,Боль,Настр,Пульс,sRPE,Hooper), двухуровневая шапка (дата+день недели сверху, метрики ниже), легенда с цветными ● , серые=пропуски, зебра, столбец «Ср.». Периоды 1/7/30/90 дней, можно выбрать команду.
  - *Анкеты* (`export_questionnaires_xlsx`): лист «Анкеты» (двухуровневая шапка: блоки ОБЩИЕ/ТРАВМЫ/ТРЕНИРОВКИ/ПИТАНИЕ/ПСИХОЛОГИЯ цветные + поля, зебра, автофильтр) + лист **«Легенда»** (расшифровка полей).
- ⚙️ **Управление**: список спортсменов с ID, блокировка/разблокировка, просмотр анкет, напоминания, календарь записи.

## АРХИТЕКТУРА / КАК ЭТО РАБОТАЕТ
- **Без ConversationHandler.** Все состояния в `self.user_states[telegram_id] = {"step": ..., "data": ..., "q_data": ...}`.
- **Опрос**: `handle_questionnaire_answer`/`handle_text` — каждый шаг это `if step == "survey_<x>":`. Ввод пульса/sRPE/цикла/жалоб — текстом через `handle_text`.
- **Анкета**: шаги `q_<ключ>`. Кнопочные — в `handle_questionnaire_answer` (callback), текстовые — в `handle_text`. Есть `step_order` для resume и `_q_ask_step` (показ вопроса).
- **БД**: SQLite. Таблицы: `athletes`, `daily_wellness` (по 1 на спортсмена в день), `questionnaires` (анкета), `banned_athletes`, `bot_settings`, `watch_data`, `surveys` и др.
- **Excel**: openpyxl.

### Важные нюансы для чтения кода
1. **SQL-безопасность**: имена колонок в SQL не подставляются через `?` — есть whitelist `allowed` в `save_questionnaire`.
2. **Многие методы анкеты** получают `update` то из callback-кнопки, то из текста (Message). Корректный паттерн: `q = update.callback_query if hasattr(update,'callback_query') and update.callback_query else None`, `user_id = update.effective_user.id if update.effective_user else q.from_user.id`, и затем `if q: q.edit_message_text(...) else: update.message.reply_text(...)`. Смотри `_ask_complaints`, `_ask_cycle_length`, `_q_save_then_block3`, `_q_show_supp_buttons`.
3. **Автосохранение анкеты** (`db.save_questionnaire`) вызывается после каждого ответа; КРИТИЧНО: сериализует `list → ", ".join` для колонки `supplements` (иначе SQLite падает `binding parameter`).
4. **Эмодзи в Excel-ячейках** ч/б — для цветных кружков в легенде используется символ ● (U+25CF) + цвет шрифта.
5. **Напоминания** и мгновения времени — Asia/Yekaterinburg (UTC+5), хранятся в `bot_settings`.
