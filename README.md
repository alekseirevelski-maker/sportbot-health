# Спортивный бот здоровья

Telegram бот для мониторинга здоровья спортсменов (14+ лет).

## Возможности

- Утренний опрос Hooper Index (Simple/Full протоколы)
- Автоматические алерты при отклонениях
- Дашборд для врачей/тренеров
- PDF-отчёты

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте `.env` файл с токеном бота:
```
SPORT_BOT_TOKEN=ваш_токен
```

3. Запустите бота:
```bash
python bot.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация / вход |
| `/survey` | Утренний опрос |
| `/my` | Мои данные |
| `/team` | Список команды |
| `/alerts` | Алерты |
| `/help` | Помощь |

## Протоколы

### Simple (U14-U16)
- Сон (1-7)
- Стресс (1-7)
- Утомление (1-7)

### Full (U17+)
- Сон (1-7)
- Стресс (1-7)
- Утомление (1-7)
- Мышечная боль (1-7)
- Настроение (1-7)
- Пульс покоя (уд/мин)
- HRV (мс)
