# Спортивный бот здоровья

Telegram бот для мониторинга здоровья спортсменов (14+ лет).

## Возможности

- Утренний опрос Hooper Index (Simple/Full протоколы)
- Автоматические алерты при отклонениях
- Дашборд для врачей/тренеров
- Экспорт в Excel (отчёты по командам, анкеты)

## 🔒 Безопасность и конфиденциальность

- Список команды доступен только врачу/тренеру — спортсмены видят только свои данные.
- Персональные данные (телефон, дата рождения, мед. детали) хранятся в зашифрованном виде (Fernet, ключ `ENCRYPTION_KEY`).
- При первом входе запрашивается согласие на обработку персональных данных (152-ФЗ).

## 📊 Индивидуальные коридоры

- Алерты генерируются только при **2 отклонениях подряд** от личной нормы (база ~30 дней) — без ложных срабатываний на разовые выбросы.
- Коридоры пересчитываются динамически при каждом опросе из последних 30 дней.
- Дополнительно работают общие пороги по возрастной группе.

## 🚀 Производительность

- Критичные операции с БД выполняются асинхронно (run_in_executor) + включён WAL-журнал.
- Rate-limit на текстовые сообщения (лимит задаётся через `.env`).

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте `.env` файл с токеном бота:
```
SPORT_BOT_TOKEN=ваш_токен
```

3. Запустите бота:
```bash
python bot.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация / вход |
| `/survey` | Утренний опрос |
| `/my` | Мои данные |
| `/team` | Список команды |
| `/alerts` | Алерты |
| `/help` | Помощь |

## Протоколы

- Младшие группы (U14-U16, Simple) — «короткий» опрос: сон, часы сна, готовность, утомление, боль, боль NRS, жалобы и пульс покоя.
- Старшие (U17+, Full) — то же + мышечная боль, построение sRPE.

Пульс покоя запрашивается в опросе у всех групп (у младших — как последний шаг, без лишних вопросов про тренировку).

## Состав тела (биоимпедансные весы)

- Поддержка умных весов GARLYN Bodyscan Master (приложение MovingLife).
- Импорт CSV: врач/тренер присылает экспорт истории, бот раскладывает записи по спортсменам через сопоставление профилей весов (`scale_profiles`).
- Метрики: вес, ИМТ, %жира, мышечная масса, вода, кости, висцеральный жир, BMR/AMR и др. — в таблице `body_composition`.
- Тренд массы показывается спортсмену в профиле; расширенные метрики — врачу/тренеру.

## Структура файлов

```
sport-health-bot/
├── bot.py               # Главный файл бота
├── config.py            # Конфигурация (админы, напоминания из .env)
├── database.py          # Работа с БД (whitelist-колонки, шифрование, персистентные сессии)
├── validator.py         # Валидаторы ввода (шкала, пульс, дата, санитизация)
├── encryptor.py         # Шифрование персональных данных (Fernet)
├── cycle_medicine.py    # Менструальный цикл и фазы
├── watch_parser.py      # Парсер файлов с умных часов
├── scale_csv_parser.py  # Парсер CSV биоимпедансных весов (MovingLife/GARLYN)
├── weekly_report.py     # Воскресный отчёт-картинка (Pillow)
├── reports.py           # Генерация отчётов (TXT)
├── tests/               # Юнит-тесты
├── requirements.txt
├── .env.example
└── data/                # Данные (БД, отчёты) — НЕ коммитится
```
